## 📌 Про проєкт

**SwiftTune** — це програма для швидкого налаштування та оптимізації продуктивності вашого ПК під керуванням **Windows 10/11**. Вона пропонує систему рівнів оптимізації та миттєвий доступ до системних утиліт у зручному інтерфейсі.

> [!IMPORTANT]
> **SwiftTune** піклується про вашу безпеку! Перед проведенням будь-яких дій програма пропонує автоматичне **створення контрольної точки відновлення системи**.

## ✨ Особливості

| | Можливість | Опис |
|:-:|---|---|
| ⚡ | **Рівнева оптимізація** | Від легкого прискорення до глибокого налаштування системи під ваші потреби |
| 🛡️ | **Захист даних** | Вбудоване створення точки відновлення Windows в один клік |
| 🛠️ | **Швидкий доступ** | Запуск ключових компонентів: `regedit`, `cmd`, `taskmgr`, `services.msc` тощо |
| 🧹 | **Очищення системи** | Видалення тимчасових файлів (Temp) та кешу DNS |
| 🔧 | **Обслуговування** | Перевірка цілісності системних файлів (SFC, DISM) та відновлення мережі (Winsock) |

## 🛠️ Додаткові інструменти

> [!NOTE]
> Окреме меню швидкого доступу для досвідчених користувачів з найбільш затребуваними функціями системного адміністрування.

| Інструмент | Що робить |
|---|---|
| 🔄 **Перезапуск Explorer** | Швидке перезавантаження `explorer.exe` при збоях робочого столу |
| 🔍 **Перевірка цілісності (SFC)** | Автоматична перевірка системних файлів через `sfc /scannow` |
| 🛠️ **Перевірка DISM** | Відновлення образу системи |
| 🧹 **Очищення Temp та кешу DNS** | Звільнення пам'яті та вирішення проблем з мережею |
| 🌐 **Відновлення Winsock** | Скидання мережевих протоколів при втраті з'єднання |
| 🚀 **Відкрити Startup** | Швидкий перехід до керування автозавантаженням |

## 🚀 Як користуватися

1. 📥 **Завантажте** останній реліз зі сторінки [Releases](../../releases).
2. ▶️ **Запустіть** `SwiftTune.exe` *(бажано від імені адміністратора)*.
3. 📖 При першому запуску **ознайомтеся** з угодою користувача та порадами.
4. ✅ Переконайтеся, що прапорець **«Створення контрольної точки відновлення»** активований.
5. 🎚️ Оберіть рівень оптимізації слайдером і натисніть **«Оптимізувати»**.

> [!TIP]
> Запускайте програму від імені адміністратора: частина налаштувань без цього не застосується.
